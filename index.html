HOTBONE PHILOSOPHY

我們不打正經職棒，
但我們的棒子比誰都還要生氣勃勃！

文華哈棒隊 (HotBone) 起源於文華高中第 14 屆的兄弟情誼。我們在紅土球場上揮灑汗水，也在社群幹話裡爭寵奪冠。對我們而言，棒球從來就不只是輸贏，而是讓一群長大後的小人物聚在一起、宣洩荷爾蒙與生命熱情的唯一理由。

01 // TRASH TALK

幹話集散地

將日常爭寵內鬥轉化為數位典藏與熱血傳奇。

02 // HEADWIND

逆風熱血敘事

不管比分落後多少，自信與費洛蒙永不熄滅。

03 // MULTIVERSE

非正經多元宇宙
