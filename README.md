## 📂 網站架構與頁面導覽
- `index.html`：**官方首頁**（Hero 主視覺、品牌宣言、無縫幹話跑馬燈、多元宇宙入口、發射費洛蒙表單）
- `roster.html`：**球員誌 (Roster)**（復古美式球員卡牌、能力值雷達、代表語錄、位置篩選）
- `legends.html`：**傳奇與 Podcast**（陳言愈滿貫砲歷史紀事、91Boner 搖滾跨界專區、Firstory Podcast 播放互動）
- `merch.html`：**球隊周邊 & 老司機深夜專欄**（酒紅選手練習衫展示、18 禁大蟒蛇彥文解鎖專欄）
- `assets/`：
  - `css/custom.css`：美式復古運動風格、彩虹光暈霓虹、微光動畫
  - `js/main.js`：跑馬燈 Hover 暫停、行動版選單、老司機解鎖邏輯、表單 Toast
  - `images/`：隊徽、中文字吉祥物、美式火焰字標

## 🚀 部署說明 (GitHub Pages)
本專案使用 GitHub Actions (`.github/workflows/deploy.yml`) 進行自動部署：
1. 任何推送到 `main` / `master` 分支的變更將自動觸發部署。
2. 靜態網頁無須編譯步驟，幾秒內即可在 `hot-bone.com` 生效。
